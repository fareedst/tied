# bundled-record-gf-trial-skill

Store-only Cursor skill for facilitators grading disposable **greenfield** clients and publishing **trial readouts** under `docs/demos/`.

## Install (TIED store repo)

```bash
cd /path/to/stdd
./tied-install.sh --allow-self-install --layers skills .
```

Then invoke **`@record-gf-trial`** from the store workspace.

## Canonical procedure

See [SKILL.md](./SKILL.md).

## Not installed on disposable clients

Listed under `manifest.json` → **`STORE_FACILITATOR_SKILLS`**, not `BUNDLED_STANDALONE_CLIENT_SKILLS`.
