### 2.3 Canonicalization rules (normative)

| Layer | Rule |
| --- | --- |
| Document root | Sort top-level keys alphabetically |
| `mcpServers` | Sort server name keys alphabetically |
| Each server object | Sort property keys alphabetically |
| `env`, `headers` | Sort nested string-map keys alphabetically |
| `args` | Preserve array order |
| Non-object `env` | Leave unchanged (tolerance); no throw unless tests require |
