# Worksheet: S-T02

**Candidate only — not canonical until W5 promotion.**

## Stressor

- **Category:** technical
- **Description:** Worker process killed after store write begins but before outcome/evidence append completes.

## Impact path

- **People:** background worker
- **Functions:** Worker execution loop, evidence append
- **Data:** Partial execution state, incomplete evidence tail
- **Dependencies / bindings:** store transaction boundaries

## Residue

- **Description:** Task remains non-terminal or ambiguous; dependents stay locked; retry can append new attempt.
- **Class:** desirable

## Business priority

P0 — stateful-reliability

## Design response

Single-writer transitions; crash leaves last committed evidence as source of truth; retry preserves task_id.
